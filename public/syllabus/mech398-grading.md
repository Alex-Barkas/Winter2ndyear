# MECH 398: Mechanical Engineering Laboratory I

## Grading Scheme
- **Tutorials**: 12% (4 x 3%)
- **Pre-Lab Quizzes**: 8% (4 x 2%)
- **In-Lab TA Assessment**: 8% (4 x 2%, team grade)
- **Virtual Team Notebook**: 8%
- **Lab Reports**: 64% (4 x 16%)

## Labs (in order)
1. Refrigeration
2. Flow in Pipes
3. Vertical Jump Height
4. Structures

Each lab runs as: pre-lab quiz (due before the lab starts) → tutorial → lab session (in-lab TA assessment) → lab report (due 10 days after the lab). The Virtual Team Notebook is a single cumulative deliverable due within 5 days of the last lab report.
